Catalog Publishing

Parses supplier files (BRP CSV, Parts Unlimited XML, WPS SKUs) and publishes full product listings to Shopify — titles, variants, images via LeMans CDN, and pricing — in a single automated run.

$ npm run catalog:brp # Ski-Doo · Sea-Doo · Can-Am $ npm run catalog:pu # Parts Unlimited XML feed $ npm run catalog:wps # WPS SKU sync
Live Inventory & Pricing

Pulls real-time stock levels and pricing from Lightspeed POS every 2 hours via Windows Task Scheduler, routes through a Redis cache to minimize Shopify API calls, and pushes delta updates only.

$ npm run inventory:cache # Redis-cached sync $ npm run inventory:check # Accuracy audit $ npm run maintenance:dedupe # Remove duplicates
Automated Dropshipping

When a Shopify order comes in for a WPS or Parts Unlimited product, the fulfillment job automatically forwards the order to the supplier API and pushes tracking numbers back to Shopify — zero manual touchpoints.

$ npm run fulfill:wps # Western Power Sports $ npm run fulfill:pu # Parts Unlimited
